# PEC 2 Visualización de Datos

Tres visualizaciones interactivas creadas para la PEC 2 de la asignatura Visualización de Datos del Máster Universitario de Ciencia de Datos de la UOC.

## Visualizaciones

- Gráfico de barras apiladas sobre la estructura por edades de cinco países.
- Gráfico de coordenadas paralelas con el conjunto de datos Iris.
- Sparklines sobre la evolución de la esperanza de vida.

## Fuentes de datos

- Banco Mundial, World Development Indicators. Licencia CC BY 4.0.
- Fisher, R. A. (1936), Iris, UCI Machine Learning Repository. Licencia CC BY 4.0.
